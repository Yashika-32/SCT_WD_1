# 🌟 HopeForAll - Donation Campaign Landing Page  
**A responsive, interactive landing page for a nonprofit donation campaign.**  

## 🚀 Live Demo  
👉 **[View Live Demo](https://yashika-32.github.io/SCT_WD_1/)**  

✅ **What's Working**  
- Responsive design on all devices  
- Functional contact form  
- Smooth animations  

⚠️ **Known Issues**  
- Mobile menu sometimes sticks (fix in progress)

---

## 📌 Features  
- **Responsive Design**: Works on mobile, tablet, and desktop.  
- **Dynamic Navbar**: Color changes on scroll + hover effects.  
- **Interactive Donation Form**: Integrated with EmailJS for submissions.  
- **Animated Progress Bars**: Visualize donation goals.  
- **Smooth Scrolling**: For better UX.  

---

## 🛠️ Technologies Used  
- **Frontend**: HTML5, CSS3, JavaScript  
- **Deployment**: GitHub Pages  
- **Tools**: Git, Font Awesome (icons), EmailJS (form handling)
